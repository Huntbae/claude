# brother-scan-fix

Brother DCP-T720DW를 Wi-Fi로 연결해 쓸 때 인쇄는 되는데 스캔만 실패하는 문제를 Windows 10/11 PC에서 진단하고 복구하는 도구입니다.

## 사용법

1. 이 폴더의 파일 4개(`brother-scan-fix.ps1`, `run-diagnose.cmd`, `run-fix.cmd`, `run-undo.cmd`)를 스캔할 PC의 한 폴더에 내려받습니다.
2. 인터넷에서 받은 파일은 Windows가 실행을 막을 수 있습니다. 각 파일을 마우스 오른쪽 버튼으로 눌러 **속성 → 차단 해제**를 체크하고 확인합니다.
3. **`run-diagnose.cmd`**를 더블클릭합니다. 진단만 하고 설정은 바꾸지 않습니다.
4. 문제가 발견되면 **`run-fix.cmd`**를 더블클릭합니다. 관리자 승인 창에서 [예]를 누르고, 적용할 작업 목록을 확인한 뒤 `Y`를 입력합니다.
5. 진단 기록은 바탕화면의 `brother-scan-report-날짜-시간.txt`로 저장됩니다. 해결되지 않으면 이 파일 내용을 공유해 주세요.

프린터를 자동으로 찾지 못하면 프린터에서 **네트워크 구성 보고서**를 인쇄해 IP를 확인한 뒤, PowerShell에서 직접 지정해 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\brother-scan-fix.ps1 -Fix -PrinterIP 192.168.0.15
```

## 점검 항목과 복구 내용

| 점검 항목 | 진단 (`run-diagnose`) | 복구 (`run-fix`) |
|---|---|---|
| 프린터 실제 주소 | 프린터 포트, 장치 정보, LAN 탐색(/24)으로 확인 | - |
| 스캐너 드라이버에 저장된 주소 | 실제 주소와 비교 (가장 흔한 원인) | '스캐너 및 카메라' 창을 열고 입력할 IP 안내 |
| PC와 프린터가 같은 네트워크인지 | 서브넷 비교 | - |
| 네트워크 프로필 '공용' | 경고 | '개인'으로 변경 |
| VPN 연결 | 경고 | - (직접 끊어야 함) |
| 방화벽 UDP 54925, 137, 161 수신 허용 | 규칙 존재 여부 확인 | 로컬 서브넷에서 오는 연결만 허용하는 규칙 추가 |
| 별도 보안 프로그램(V3, 알약 등) | 설치 여부 경고 | - (해당 프로그램에서 예외 등록 필요) |
| WIA, 기능 검색 서비스 | '사용 안 함' 여부 확인 | 재시작, '사용 안 함'이면 기본값(수동)으로 복원 |
| 스캐너 응답 | WIA로 연결 시험, 오류 코드 해석 | 복구 후 재시험 |
| Brother 소프트웨어 | 설치 여부, 버전 | - |

## 되돌리기

- **`run-undo.cmd`**: 이 도구가 추가한 방화벽 규칙(`Brother Network Scan (brother-scan-fix) ...`)만 제거합니다.
- 네트워크 프로필은 **설정 → 네트워크 및 인터넷 → (연결된 네트워크) 속성**에서 '공용'으로 되돌릴 수 있습니다.
- 서비스는 재시작만 하며, 시작 유형은 '사용 안 함'일 때만 Windows 기본값(수동)으로 되돌리므로 별도로 되돌릴 필요가 없습니다.

## 한계와 주의사항

- **드라이버 주소는 자동으로 바꾸지 않습니다.** Brother 드라이버의 저장 형식이 공개되어 있지 않아 레지스트리를 직접 수정하지 않고, 설정 창을 열어 입력할 값을 안내합니다.
- 드라이버가 주소를 IP가 아닌 노드 이름(BRW...)으로 저장한 경우에는 주소 불일치를 감지하지 못합니다. 이 경우에도 스캐너 응답 시험이 실패하면 설정 창을 엽니다.
- 네트워크 프로필을 '개인'으로 바꾸는 작업은 **집이나 사무실처럼 신뢰할 수 있는 네트워크**에서만 진행하세요.
- 프린터 화면에 표시되는 오류(용지 걸림, 덮개 열림 등)는 이 도구의 대상이 아닙니다.
- 검증 범위: PowerShell 문법 검사, Windows 10 / PowerShell 5.1 호환성 검사(PSScriptAnalyzer), 모의 환경에서의 진단·복구 흐름 시험까지 마쳤습니다. 실제 DCP-T720DW 기기에서는 시험하지 않았습니다.

## Mac 사용자

이 도구는 Windows 전용입니다. Mac에서는 다음을 순서대로 확인합니다.

1. **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 Brother iPrint&Scan을 허용합니다(macOS 15 이상).
2. iPrint&Scan에서 **기기 선택**을 다시 해서 현재 프린터 IP로 연결합니다.
3. VPN을 끄고, Mac과 프린터가 같은 Wi-Fi에 연결되어 있는지 확인합니다.
4. 급할 때는 macOS 기본 앱 **이미지 캡처**로 스캔할 수 있습니다.
